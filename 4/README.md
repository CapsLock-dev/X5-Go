# Сервис заказов

## Запуск
```bash
go run ./cmd/orders
HTTP_ADDR=:9090 go run ./cmd/orders
```
Переменная окружения HTTP_ADDR определяет адрес на котором слушает сервис. 
По умолчанию `HTTP_ADDR=:9090`

## Структура
| Пакет | Назначение |
|---|---|
| `cmd/orders` | `Связывает все пакеты и запускает приложение` |
| `config` | `Чтение конфигурации` |
| `handler` | `Обработчик запросов` |
| `model` | `Описание модели заказа` |
| `repository` | `Хранение заказов` |
| `service` | `Бизнес-логика: валидация и управление заказами` |
