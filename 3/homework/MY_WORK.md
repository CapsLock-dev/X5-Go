# Сервис уведомлений

Автор: Сидоров Я.Я. Б25-523

## Что делает программа

Отправляет уведомления пользователю двумя способами - электронная почти и пуш-уведомление

## Как запустить

Версия go - 1.22

```bash
cd 3
go run ./cmd/notify
go test ./practice
```

## Проверенные случаи

В случае успешной отправки в историю добавляется отправленное сообщение

В случае пустого текста возвращается ошибка, история не изменяется

В случае отсутствующей настройки возвращается ошибка, история не изменяется

В случае паники одного канала возвращается ошибка, следующий канал получает сообщение как обычно

## Обработка ошибок

Dispatch в случае ошибки возвращает её сразу, не закончив цикл из-за этого сообщение может пройти не по всем каналам.
SafeDispatch в случае ошибки записывает её и продолжает выполнение цикла, даже если это паника.

error.Is используется для проверки типа ошибки (в случаях Пустой текст и Сломанная реализация)
error.As используется для получения ошибки определенного типа (в случае Нет настройки)

паника вызывет раскрутку стека, при которой первым выполняется defer, где recover ловит панику и возвращает ошибку.
в случае без паники recover возвращает nil и ошибка не возвращается.
